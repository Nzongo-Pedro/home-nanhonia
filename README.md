# Nanhonia

Website institucional desenvolvido para apresentação da marca Nanhonia, com foco em identidade visual, conteúdo institucional e experiência web responsiva.

## Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- AOS — Animate On Scroll

## Estrutura

```text
home-nanhonia/
├── index.html
├── assets/
│   ├── css/
│   ├── img/
│   └── ...
└── README.md
```

## Características

- Layout responsivo
- Navegação institucional
- Secções de apresentação e informação
- Componentes Bootstrap
- Animações com AOS
- Organização de assets
- Preparado para publicação web estática

## Publicação

O projeto pode ser publicado como site estático através do GitHub Pages ou de qualquer servidor web compatível com HTML, CSS e JavaScript.
